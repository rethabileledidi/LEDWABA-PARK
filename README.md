# 🍺 LEDWABA PARK PUB & GRILL Website

A website for my dad's pub and grill — built to showcase the menu, hours, location, and vibe, and to give customers an easy way to find us online.

## 📖 About
 A family run business since 2015. 

## ✨ Features

- Home page with hero section and highlights
- Menu page (food & drinks)
- About / our story section
- Location & hours
- Contact / booking info
- Responsive design (mobile, tablet, desktop)

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript


## 🎨 Design System

The site uses CSS custom properties (variables) to keep styling consistent across pages.

### Font Sizes
```css
--font-size-s: 0.9rem;
--font-size-n: 1rem;
--font-size-m: 1.12rem;
--font-size-l: 1.5rem;
--font-size-xl: 2rem;
--font-size-xxl: 2.3rem;
```

### Font Weights
```css
--font-weight-normal: 400;
--font-weight-medium: 500;
--font-weight-semibold: 600;
--font-weight-bold: 700;
```

### Border Radius
```css
--border-radius-s: 8px;
--border-radius-m: 30px;
--border-radius-circle: 50%;
```
